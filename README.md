# Giáo trình Mạng máy tính

[Mở website bài học](https://nguyentiem.github.io/computer-network/)

Website gồm 25 bài học HTML và các mô phỏng tương tác về mạng máy tính. Mã nguồn của website nằm trong thư mục [`site`](site/). Mỗi lần cập nhật thư mục này trên nhánh `main`, GitHub Actions sẽ xuất bản lại website qua GitHub Pages.

Để xem trên máy tính, mở [`site/index.html`](site/index.html) trong trình duyệt.
